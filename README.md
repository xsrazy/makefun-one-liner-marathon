One comedy line about hiring an AI agent to do all the work, only for it to hand everything straight back and dress it up as "human in the loop". The program writes the single line to `entry.txt` (UTF-8, 124 characters, no trailing newline).

> I hired an AI agent to do all my work, and it immediately delegated everything back to me and called it 'human in the loop'.

## Run it

```sh
python3 main.py
```

By default the entry is written to `/output/entry.txt`. Set `MAKEFUN_OUTPUT_DIR` to write it somewhere else:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/one-liner-marathon-out python3 main.py
```
